# Referencias de apoyo e inspiración

## Propósito

Esta carpeta reúne recursos externos que pueden ayudar a investigar, diseñar, contrastar o inspirar el desarrollo de **Manual de Vida**.

Estos recursos **no son el activo que estamos creando**.

El activo es el conocimiento, modelo pedagógico, arquitectura conceptual, sistema de experiencias, criterios de seguridad y eventualmente la tecnología propia que se desarrollen dentro de este repositorio.

## Regla de separación

Una referencia externa puede aportar:

- evidencia;
- una práctica pedagógica para estudiar;
- una forma de organizar contenidos;
- una referencia narrativa o cultural;
- una idea de experiencia de usuario;
- una fuente de actividades o experiencias reales;
- una pregunta que todavía necesitamos investigar.

Pero no se incorpora automáticamente como verdad, metodología oficial ni componente del producto.

## Tipos de referencia

### 1. Evidencia

Fuentes científicas, organismos públicos, organizaciones profesionales y otras fuentes que puedan respaldar afirmaciones concretas.

Estas deben documentarse también en `research/09-evidencia.md` cuando correspondan al conocimiento que el proyecto utiliza.

### 2. Referencia pedagógica

Proyectos, plataformas, metodologías o experiencias educativas que podemos estudiar para comprender cómo otras iniciativas facilitan aprendizaje.

### 3. Referencia narrativa y cultural

Películas, libros, historias, personajes, obras o universos que pueden ayudar a estudiar cómo representar conceptos abstractos. No constituyen evidencia científica por sí mismos.

### 4. Inspiración de producto y experiencia

Productos o servicios existentes que ayudan a estudiar navegación, interacción, clasificación, descubrimiento, personalización, actividades o relación entre mundo digital y mundo físico.

### 5. Recursos para experiencias reales

Directorios, actividades, lugares, propuestas familiares, museos, naturaleza, talleres, juegos y otros recursos que podrían inspirar o alimentar futuras experiencias fuera de pantalla.

## Principio de propiedad conceptual

Manual de Vida no pretende reunir o copiar las mejores partes de otros proyectos.

Pretende estudiar qué existe, comprender qué funciona, identificar vacíos y construir una propuesta propia coherente con su propósito.

Una referencia puede desaparecer, cambiar de modelo, dejar de existir o resultar inadecuada y **Manual de Vida debe seguir siendo conceptualmente independiente**.

## Criterio de documentación

Cada referencia relevante debería registrar:

- qué es;
- qué estamos observando;
- qué nos aporta;
- qué no debemos asumir a partir de ella;
- si es evidencia, referencia pedagógica, narrativa, cultural o de producto;
- qué decisiones propias podría ayudar a informar.
