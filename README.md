# Manual de Vida

> Nombre de trabajo. El nombre definitivo podrá cambiar cuando la identidad del proyecto esté más clara.

Manual de Vida es un proyecto educativo orientado a desarrollar autoconocimiento y habilidades para la vida. Busca ayudar especialmente a jóvenes a comprender mejor lo que les ocurre, distinguir hechos de interpretaciones, reconocer emociones y señales corporales, tomar decisiones y desenvolverse con mayor autonomía.

## Principio rector

No pretende entregar una receta única para vivir. Busca ofrecer herramientas para observar, comprender, decidir y actuar con mayor conciencia.

## Áreas iniciales

- Mente y pensamiento
- Emociones
- Cuerpo y conciencia corporal
- Relaciones
- Internet y entorno digital
- Finanzas
- Identidad y dirección
- Acción, proyectos y aprendizaje

## Distinciones fundamentales

- Hecho ↔ interpretación
- Expectativa ↔ realidad
- Emoción ↔ acción
- Control ↔ no control
- Deseo ↔ necesidad
- Objetivo ↔ proceso
- Error ↔ aprendizaje
- Comparación ↔ contexto
- Pensamiento ↔ evidencia

## Criterio de desarrollo

Cada contenido deberá distinguir, cuando corresponda:

1. evidencia disponible;
2. interpretación o hipótesis;
3. propuesta pedagógica;
4. reflexión filosófica o personal.

Los temas sensibles deberán desarrollarse con especial cuidado, fuentes trazables y límites claros entre educación, orientación y atención profesional.

## Arquitectura del proyecto

La aplicación no será el punto de partida. Primero se construirá una fuente de verdad conceptual, pedagógica y documental. La interfaz y la lógica de producto se desarrollarán sobre esa base.

## Estado

**Fase 0 — Fundación y arquitectura conceptual.**

El repositorio comienza como fuente de verdad del proyecto. Las decisiones posteriores deberán poder rastrearse hasta principios, evidencia, hipótesis o experimentos identificables.
