# 07 — Privacidad y protección de datos

## Principio general

Cuando el usuario es un niño o adolescente, la privacidad debe considerarse una condición estructural del producto, no una función secundaria.

## Minimización

El sistema deberá recolectar únicamente la información estrictamente necesaria para proporcionar la experiencia educativa y operar el servicio.

Antes de incorporar un nuevo dato deberán responderse:

1. ¿Para qué se necesita?
2. ¿Es realmente necesario?
3. ¿Puede lograrse el mismo objetivo sin almacenarlo?
4. ¿Quién podrá acceder?
5. ¿Durante cuánto tiempo se conservará?
6. ¿Qué ocurre si el usuario decide no proporcionarlo?

## No vigilancia

El producto no deberá diseñarse como una herramienta para que adultos observen permanentemente el pensamiento, emociones, conversaciones o comportamiento del niño.

Las funciones para acompañamiento adulto deberán tener límites claros, finalidad educativa y salvaguardas de privacidad.

## Datos sensibles

Se deberá evitar almacenar innecesariamente:

- confesiones personales;
- información de salud;
- información familiar sensible;
- ubicación precisa;
- datos de contacto de terceros;
- información financiera personal;
- conversaciones privadas;
- inferencias sobre personalidad o estado emocional.

## Personalización

La personalización visual deberá poder realizarse con datos locales o mínimos siempre que sea posible.

## IA y datos

Las conversaciones con sistemas de IA no deberán convertirse automáticamente en una base permanente sobre la vida del niño.

Antes de almacenar, reutilizar o enviar información a un proveedor externo deberán definirse finalidad, necesidad, retención, acceso y controles correspondientes.

## Analítica

Las métricas deberán priorizar el aprendizaje y la seguridad. Se evitarán sistemas que incentiven la recopilación masiva de comportamiento infantil para publicidad, perfilado o maximización de engagement.

## Estado

**Versión 0.1.** Principios iniciales. Requiere revisión legal y técnica específica antes de cualquier lanzamiento con usuarios reales.
